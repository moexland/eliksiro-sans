FONTLOG for Eliksiro Sans
-------------------------

This file provides detailed information on the Eliksiro Sans Font Software.
This information should be distributed along with the Eliksiro Sans fonts and
any derivative works.


Basic Font Information
----------------------

Eliksiro Sans is a Simplified Chinese sans-serif variable font, with weights
from Thin (100) to Bold (700). It is a modified version of Frex Sans GB 1.100
by The Frex Sans Project Authors, with the characters it lacks taken from
IBM Plex Sans SC 1.1.0 by IBM Corp.

It comes as EliksiroSans-VF.otf, an OpenType font with CFF2 outlines, and as
EliksiroSans-VF.woff2, the same font compressed for the web. For websites, the
npm package @moexland/eliksiro-sans has it in WOFF2 slices with a CSS entry, so
that browsers download only the slices a page uses.

Eliksiro Sans is licensed under the SIL Open Font License, Version 1.1; see
OFL.txt. It is built with the pipeline at
https://github.com/moexland/eliksiro-sans.


ChangeLog
---------

27 October 2026 (Moonchime) Eliksiro Sans Version 0.100
- Added the 16,292 code points of IBM Plex Sans SC that Frex Sans GB lacks.
  Two compatibility ideographs and eight GB 18030 private-use code points map
  to the Frex Sans GB glyphs of the same characters; U+22EF is a copy of
  Frex Sans GB's centred U+2026, as IBM's sources have no glyph for it; the
  others take the IBM Plex Sans SC glyphs, with Frex Sans GB's vertical origin
  (880) and vertical advance (1000).
- Mapped U+F995, U+F9E7 and U+F9F1, compatibility ideographs in GBK, to the
  glyphs of U+79CA, U+88CF and U+96A3.
- U+2022 is now a bullet: IBM Plex Sans's, enlarged by 5% as the Latin of
  Frex Sans GB is. It used to be the Latin middle dot.
- Fixed contours that interpolated wrongly between masters: the start points
  in U+6961, U+6B1D and U+9476 from IBM Plex Sans SC and in U+7296 from
  Frex Sans GB, and the contour order in U+2504 from Frex Sans GB.
- Renamed to Eliksiro Sans.
- Line metrics: ascender 880, descender -120 and line gap 500 in both hhea
  and OS/2, with USE_TYPO_METRICS on, so that ideographs sit in the middle of
  the line; OS/2 win ascent and descent from the bounds of all glyphs.
